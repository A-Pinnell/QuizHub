PREFERENCES

				
Options

				
				

					
Keyboard guide

					

						

							
Main menu

							

								Arrow keys move between courses; Page Up/Down changes course
								pages. Enter or Space opens a focused control.
							

						

						

							
Menus and options

							

								O opens or closes Options; P opens Party Mode. Tab and Shift+Tab
								move between controls in a menu. Arrow keys change radio,
								select, and slider choices. Escape closes a menu or returns from
								quiz setup.
							

						

						

							
Quiz

							

								Arrow keys or 1–4 / A–D focus answers. Enter selects an answer,
								then advances after it is answered. For short-answer questions,
								type an answer and press Enter to submit. Escape ends the quiz.
